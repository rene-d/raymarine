# Analyse du SSH du MFD Raymarine — synthèse exhaustive

## Ouvrir une session SFTP

Le crédential d'accès `media_rw` est le champ **`SshPrivateKey`** du fichier
`user_settings_<uuid>.json` de l'app **RayConnect**. `rm_ssh.py`
l'exploite directement :

```sh
./rm_ssh.py path_to/user_settings_<uuid>.json         # ouvre une session SFTP sur media_rw@MFD
```

La clé publique correspondante n'est pas contenue dans le firmware : elle a été
enrôlée sur ce MFD précis. Elle ne rouvrira donc que les
MFD sur lesquels RayConnect s'est déjà appairé.
